# Keyboard Screen Studio

*Read in [English](README.md) · [简体中文](README.zh-Hans.md)*

Keyboard Screen Studio (KSS) — застосунок для вертикального екрана клавіатури
Linx68. Він малює стан системи, годинники, погоду, біржові котирування,
інформацію про медіа та теми із зображеннями на екран 142×428 і автоматично
надсилає їх на клавіатуру через її image API.

Інтерфейс і теми доступні **англійською, українською та спрощеною китайською**;
мова перемикається на льоту в розділі *Інші налаштування*.

## Поточний стан

- **Windows:** v1.10.4 на Avalonia UI. Це платформа, для якої виходять релізи.
- **macOS:** крос-платформний проєкт і скрипти пакування збережено в репозиторії.
  Збірки для Intel і Apple Silicon ще потребують перевірки на реальному
  пристрої й поки не виходять як стабільний реліз.
- **Linux:** не випущено. Шари даних, рендерингу та платформи залишають для
  цього місце.

## Можливості

- 33 вбудовані теми: моніторинг, час, інформація, музика, точкова матриця та
  годинник на зображенні — зокрема конструктор екрана, що складає обрані вами
  віджети у власну розкладку, детальний апаратний монітор зі змінними
  сторінками, курси валют, крипто Binance зі спарклайнами, помодоро-таймер,
  сітка контрибуцій GitHub, диски, пінг-монітор, світові годинники, відлік до
  подій, календар з ICS-стрічки і повітряні тривоги України за даними
  alerts.in.ua (лише інформаційно — ніколи не єдине джерело оповіщення) з
  опційним пріоритетом тривоги: на весь екран чи попап-банером, до відбою чи
  на заданий час.
- Нічний розклад (зміна теми і зниження яскравості у задані години), карусель
  тем, що ротує обраний набір екранів, Telegram-попапи з вашого акаунта поверх
  будь-якої теми та опційні Windows-сповіщення (ліміти Claude, клавіатура
  офлайн, цінові алерти) з кулдаунами проти спаму.
- Перемикання тем з самої клавіатури: крутілка гучності Linx68 гортає теми
  вперед/назад, натиск ставить карусель на паузу — з привʼязкою до клавіатури
  за VID:PID і опційним гасінням клавіш гучності, або через перепризначені у
  комбінація, яку ви записуєте самі, щоб гучність не зачіпалась — працює
  незалежно від того, чи вміє плата VIA/QMK. Типово вимкнено.
- Індивідуальні інтервал оновлення та акцентний колір для кожної теми,
  12/24-годинний формат і одиниці °C/°F, схід/захід сонця та якість повітря
  на екрані погоди, рядок портфеля в акціях за кількістю акцій, додаткові
  клавіатури з дзеркалом кожного кадру, а також експорт/імпорт налаштувань
  без секретів у файлі.
- Живий перегляд 142×428 із збереженням безпечної зони рядка стану прошивки.
- Власний акцентний колір, шрифт екрана, безпечна зона вмісту та компонування
  годинника на зображенні.
- Світла, темна та системна теми застосунку — незалежно від того, що малюється
  на клавіатурі.
- Періодичне оновлення та надсилання, автоперемикання медіатем, робота в треї
  та запуск разом із системою.
- Майстер першого запуску, який просить лише IP-адресу клавіатури.
- Витрати AI (у розробці) читаються з Tokscale, який ви встановлюєте
  самостійно; KSS ніколи не зберігає облікові дані платформ.
- Тема використання Claude: ковзні 5 годин, тиждень по всіх моделях і тиждень
  однієї моделі — три горизонтальні смуги з часом до скидання кожної. Це
  справжні цифри вашого акаунта: екран користується входом, який Claude Code уже
  тримає на ПК, тож вставляти й входити нікуди не треба. Подробиці — у
  [PRIVACY.md](PRIVACY.md).

## Вимоги

- Windows 10 19041 або новіша.
- Комп'ютер і клавіатура в одній локальній мережі.
- Увімкнений «Image API» в меню клавіатури; показану адресу треба ввести в KSS.

Завантажте `KeyboardScreenStudio-v1.10.4-win-x64.zip` з розділу Releases,
розпакуйте та запустіть `KeyboardScreenStudio.exe`. Реліз самодостатній —
окремо встановлювати .NET не потрібно.

## Збирання з коду

```powershell
dotnet restore KeyboardScreenStudio.sln
dotnet build src/KeyboardScreen.App.Avalonia/KeyboardScreen.App.Avalonia.csproj -c Release
dotnet run --project tests/KeyboardScreen.SmokeTests/KeyboardScreen.SmokeTests.csproj -c Release
```

Створити портативний пакет для Windows:

```powershell
./tools/Publish-Portable.ps1
```

> Локально краще встановити .NET 9 SDK, щоб отримати повний набір діагностики
> Avalonia під час компіляції. .NET 8 SDK теж збирає рішення — з одним
> попередженням про версію аналізатора.

## Переклади

Рядки інтерфейсу лежать у трьох вбудованих каталогах у
`src/KeyboardScreen.Core/Localization/`:

| Файл | Мова |
| --- | --- |
| `Strings.en.json` | англійська |
| `Strings.uk.json` | українська |
| `Strings.zh-Hans.json` | спрощена китайська |

Усі три файли мають однаковий набір ключів. Щоб додати мову, додайте запис до
`AppLanguageInfo.All`, створіть відповідний `Strings.<id>.json` і зареєструйте
його як `EmbeddedResource` у `KeyboardScreen.Core.csproj`. Smoke-тести валять
збірку, якщо каталоги розійшлися, якщо значення порожнє або якщо переклад не
має тих самих заповнювачів `{0}`…`{n}`, що й англійський.

Текст на екрані малюється на ширині 142 px, тому ключі з префіксом `Screen*`
мають лишатися короткими всіма мовами — рендерер обрізає їх трикрапкою, а не
переносить.

затримкою, неточними або змінитися без попередження; інформація про акції
показується для відображення й не є інвестиційною порадою. Див.
